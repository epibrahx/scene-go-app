## 二、产品红线（不可违反）

| # | 红线 | 原因 |
|---|---|---|
| 1 | **纯黑极简、无 emoji** | 图标用 lucide / 文字国家码；emoji 渲染跨平台不一致 |
| 2 | **界面文案禁技术术语** | SOP/VLM/zh-CN/GPS/v3.2 等用户不懂的一律禁止 |
| 3 | **禁止上滑手势触发** | iOS 系统上滑冲突，用长按/点击/横滑替代 |
| 4 | **操作必有反馈** | 按压态 / loading / 成功 / 失败，四态齐全 |
| 5 | **不造假数据** | 全真实管线，无 mock 占位 |
| 6 | **紧急动作防误触** | 长按 0.6s + 进度环 + 震动确认 |

## 三、核心设计决策（仍然有效）

### 3.1 安全体系

- **紧急号码按意图排序**（非传统分类）：191 遇到危险 / 1669 身体不适 / 1155 旅游纠纷
- **长按拨打**：0.6s 长按 + 进度环动画 + 震动反馈，防止误触成本极高的紧急拨号
- **SafetyFAB 直达 08**：SCN-19 决策，跳过 L0 中间层，直接打开完整安全详情抽屉
- **SafetyFAB 常驻** z-index:999，从任何页面可达，不受导航栈限制
- **安全数据发布门**：26 国安全信息需经人工审核才能公开（`publicationGate.ts`）

### 3.2 目的地切换

- **定位仅建议，永不自动切换**：GPS 检测到跨境时弹出 09 位置切换模态，需用户确认
- **切换前需预览**：显示新目的地信息后，用户确认才生效
- **当前国确认行**：安全相关页面显示「泰国·曼谷」弱提示，防止打错国家号码

### 3.3 导航原则

| 原则 | 规则 | 适用 |
|---|---|---|
| P1 推入下钻 | 同层级详情页用 Push（右进左退），支持右滑返回 | 01→07、13→10 |
| P2 模态中断 | 需决策的任务用模态（scale+fade），点遮罩/✕ 关闭 | 01→06、01→09 |
| P3 安全独立 | 紧急功能不受导航栈限制，SafetyFAB 始终可达 | 任意→08 |

### 3.4 交互规范

- **触控目标** ≥ 44px（WCAG）
- **最小字号** ≥ 11px
- **对比度**：主内容 ≥ 4.5:1，大字 ≥ 3:1
- **圆角体系**：6 / 10 / 12 / 16 / 20（对应 tag / 小按钮 / 主按钮 / 卡片 / FAB）
- **Reduce Motion**：所有动画有瞬切降级（fade-only 150ms）

### 3.5 语音交互

- **按住说话**（HoldMic）：onPressIn 开始识别 → onPressOut 停止 → 自动成卡
- **01 屏不再有独立 MicBtn**：语音触发归中央 HoldMic，InputBar 仅保留拍照和文字
- **iOS 原生语音识别**：SFSpeechRecognizer + AVAudioEngine，locale fallback（zh-CN → zh-* → en-US）

## 五、技术架构要点

- **状态驱动路由**：纯 `appReducer` State 驱动（无 React Navigation），Route 类型 = 11 屏
- **核心引擎**（`expressionEngine.ts`）：processImage / generateCard / askFollowUp / replyToUtterance
- **卡栈**（`cardStackStore.ts`）：zustand vanilla，动态卡入栈 + Tap&Talk 兜底卡恒在末尾
- **AI 网关**：OpenRouter chat completions API，结构化 JSON 返回（ScenarioResult / CardData / MenuData）
- **安全数据**：26 国候选信息 + publicationGate 审核门（`src/data/safety/`）
- **离线/持久化**：AsyncStorage（sessions + notes + settings）
